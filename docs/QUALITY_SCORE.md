## 4. 复算方式

用户恢复集中验证后，在插件根目录执行：

```sh
export PATH=/home/gh/.local/toolchains/go/bin:$PATH
make coverage
make lint
```

覆盖率按每个报告行的语句数加权，命中次数 >0 即覆盖；不可平均各文件百分比求整体值。执行日志里的 80.0%/85.9% 是重构前记录，81.49%/87.98%、83.16%/85.95%、83.32%/85.95%、83.74%/86.10%、88.48%/92.11%（2026-10-11）、87.04%/91.67%（2026-10-12）是后续报告；属于不同快照。

文档检查只保证链接、索引和必填节；并发行为另由 Go 回归与 race 验证。新的真实宿主部署、其他平台和流式既有边界仍需分别验证。
